# 短編ネタ出し

## リクエスト
$ARGUMENTS

## 実行手順

1. **既存短編の確認**
   - @短編集/短編テーマ一覧.md を読み、類似テーマがないか確認
   - 該当カテゴリの既存短編を把握

2. **世界設定の参照**
   - @集落の人々の生活.md
   - @隊商システム総合.md
   - @主要登場人物データベース.md
   - その他、テーマに関連する設定ファイル

3. **アイデア提案（3案）**
   各案について以下を含める：
   - **タイトル案**
   - **あらすじ**（3〜5行）
   - **主要登場人物**（既存キャラまたは新規提案）
   - **舞台**（集落名、季節、状況）
   - **テーマ・見どころ**
   - **世界設定との接点**（どの設定要素を活かすか）

4. **既存短編との差別化ポイント**を明記
