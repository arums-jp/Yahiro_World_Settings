# 短編追加ワークフロー

## 入力
$ARGUMENTS

## 手順

1. **カテゴリ構造の確認**
   - @短編集/短編テーマ一覧.md を読んでカテゴリを確認
   - 指定されたカテゴリ・サブカテゴリの既存ファイルを確認

2. **ファイル番号の決定**
   - 該当ディレクトリ内の最大番号を確認
   - 次の連番を割り当て
   - 連番は、100未満であれば、01、02、03・・・のように2桁を使用

3. **ファイル作成**
   - パス: `短編集/[カテゴリ]/[サブカテゴリ]/[番号]_[タイトル].txt`
   - テンプレート:
     ```
     【タイトル】

     （本文をここに記述）
     ```

4. **一覧への登録**
   - `短編テーマ一覧.md` に新規エントリを追加

5. **整合性の簡易チェック**
   - タイトルから推測される設定要素と既存設定の矛盾がないか確認
