# 短編執筆支援

## リクエスト
$ARGUMENTS

## 執筆プロセス

1. **関連設定の収集**
   - テーマに関連する設定ファイルを特定・読み込み
   - 必要な固有名詞、技術、社会制度を把握

2. **視点レベルの確認**
   - @視点別設定分類.md を参照
   - 登場人物が「知り得る情報」の範囲を確認

3. **既存短編のトーン参照**
   - 類似テーマの既存短編を1〜2本読み、文体を把握

4. **執筆**
   - 2000〜4000字程度
   - 世界観に沿った描写
   - 住民の視点から見た日常・非日常

5. **設定整合性の自己チェック**
   - 使用した固有名詞・設定要素のリストアップ
   - 矛盾がないことを確認
